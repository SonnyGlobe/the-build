📖 How to Use the NAP Build Finder

🧠 Overview

TheNAP Build Finder Toolconsolidates data from multiple sources into a single view to provide visibility on upcoming builds, including estimated days and target completion dates for each build stage.

Main Data Sources:

  • Build Dashboard Source Data(CFS File)
  • Nomination Tracker(DMCP File)

⚡ Build Solution Options

⭐ NAPA – NAP Augmentation

Search by NAP ID to view all NAPA-related builds.

⭐ NAP Finder

Search by Latitude/Longitude to locate the nearest build to a specific location.

⭐ Nomination File

Displays entries directly from the DMCP Nomination Tracker.

Note:Dropped statuses are excluded from results.

⭐ Live Search Tab

Performs a fuzzy search — returning results even if search terms are not exact matches.

🔑 Key Results Displayed

  • Field
  • Build Solution
  • Build Stage
  • Sub-Build Stages
  • Date Calculation

🔘 Buttons & 🕹️ Controls

ControlFunction
SearchPerform a query by NAP ID or Lat/Long depending on the selected Build Solution.
Export CSVDownload the processed dataset with computed results.
Clear SearchReset all search inputs and display all rows again.

💡 Tips & 📝 Notes

  • The Build Solutions tab performs exact match searches.
  • Dropped accounts or stages are automatically excluded from results.
  • Always usedecimal formatfor Latitude/Longitude inputs (e.g.,14.5995, 120.9842).
  • TheCRFS Calculatorprovides estimated CRFS dates based on standard SLA timelines and does not account for potential execution or approval delays.
