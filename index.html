📖 How to Use Live Tracker Tool

🧠 Overview

This tool works onLive Trackerand computes estimated days and completion dates for each build stage based on the dataset. It supports three main Build Solutions.

⚡ Build Solution Options

⭐ NAPA

Search by NAP ID and display results for NAPA accounts. Blocked stages or accounts will not display results.

  • NAPA COMPLEX
  • NAPA SIMPLE - SOLUTION 2
  • NAPA SIMPLE - SOLUTION 3
  • NAPA SIMPLE - SOLUTION 4

⭐ NAP Finder

Search by NAP ID or Lat/Long and locate all nearest facilities from the provided location.

  • ODN EXTENSION
  • NAP RELOCATION

⭐ Nomination File

Displays entries from the Nomination tracker dataset for review and processing.

🔑 Key Columns Used

  • SUB BUILD STAGES:Determines the number of days to add for the stage.
  • PSOW ENDORSEMENT DATE:Start date of the stage (MM/DD/YYYY).
  • BUILD STAGE:Stage name; affects how days are computed.

🗓️ Date Calculation

  1. Look up theSUB BUILD STAGESvalue and map it to a number of days using the internal day map.
  2. Add the number of days to thePSOW ENDORSEMENT DATEto get the estimated completion date.
  3. Output format:<days> | <completion_date>.
  4. If the date is missing or invalid, the result isN/A.

🔘 Buttons & 🕹️ Controls

  • Search:Search dataset by NAP ID or Lat/Long depending on Build Solution.
  • Update Results:Recompute days and completion dates after filtering or dataset change.
  • Export CSV:Download processed dataset with calculated results.
  • Clear Search:Clears search input and resets results.

🔍 Live Search

  • Live Search:Type any keyword (e.g. NAP ID, account name, or any column value). The table filters live as you type.
  • Clear:ClickClearto reset and display all rows again.

💡 Tips & 📝 Notes

  • Only rows matching the selected Build Solution are processed.
  • Dropped accounts or stages are excluded in NAPA searches.
  • Dates must be inMM/DD/YYYYorM/D/YYYYformat.
  • "Days to add" = full days after the PSOW Endorsement Date.
  • "N/A" means missing date, unknown stage, or invalid column.
