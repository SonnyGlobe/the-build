📖 How to Use the NAP Build Finder

🧠 Overview

The NAP Build Finder Tool consolidates data from multiple sources into a single view to provide visibility on upcoming builds, including estimated days and target completion dates for each build stage.

Main Data Sources:

  • Build Dashboard Source Data (CFS File)
  • Nomination Tracker (DMCP File)

⚡ Build Solution Options

⭐ NAPA – NAP Augmentation

Search by NAP ID to view all NAPA-related builds.

⭐ NAP Finder

Search by Latitude/Longitude to locate the nearest build to a specific location.

⭐ Nomination File

Displays entries directly from the DMCP Nomination Tracker.

Note:Dropped statuses are excluded from results.

⭐ Live Search Tab

Performs a fuzzy search — returning results even if search terms are not exact matches.

💡 Tips & 📝 Notes

  • Build Solutions Tab performs exact match searches.
  • Dropped accounts or stages are automatically excluded from results.
  • Always use decimal format for Latitude/Longitude inputs (e.g., 14.5995, 120.9842).
  • The CRFS Calculator provides estimated CRFS dates based on standard SLA timelines and does not account for potential delays in execution or approval.
